未来教程只有满足以下条件才能标记为“可执行”：

1. 只调用当前公开 API
2. 使用合成或允许再分发的 fixture
3. 默认无网络可运行
4. 在 CI 中执行关键代码单元
5. 外部数据/大型模型单元明确写出前置条件
